# spasix.eu

The web page of **SPASIX**, a six-axis motion platform for sim racing: plain static files in
[`docs/`](docs/), served by GitHub Pages.

The page and its media — the clips cut from the design's film, their posters, the logo and the
icons — are written here by a script in the project's design repository (`webpage/export_site.py`);
they are not edited by hand in this one.
